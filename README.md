A single loading-screen tip (97 characters) for stressed developers and AI coding agents: your agent just said "Done!" — give it a minute while it finds out what "done" actually broke. `main.py` writes the tip to `entry.txt` in the output directory, validated as one line of 1–200 characters.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
